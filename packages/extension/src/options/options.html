SecretSentry

Sites

SecretSentry only reads the chat box on these sites. On any other site it isn't loaded at all.

    What SecretSentry keeps

    • Saved on this device: the on/off switch and this site list. Nothing else.
    • Never saved: your messages, your keys, or anything it found. It checks text in memory and forgets it right away.
    • Never sent: it makes no network requests, has no analytics and loads no remote code.
    • Changes to sites apply after you reload those pages.
